# ARAM Mayhem website

Next.js (TypeScript) app. Each tab shows the work of one part of the repo, read
straight from the repo at build time, so the site follows whatever is on the
branch it is built from:

| Tab | Reads | Missing until |
| --- | --- | --- |
| My Stats | `dashboard/` (embedded) | PR #2 |
| China Stats | `data/cn/` | PR #5 |
| Simulator | `simulator/viewer/` and `simulator/viewer/replay-data/` (generated by `make replay`) | PR #4 |
| PBE | `data/pbe/kiwi-s3.json` | PR #1 |
| any other | a folder with a `site-tab.json` | — |

A tab whose data isn't in the repo yet says which pull request it is waiting for.

## Adding a tab

Put a `site-tab.json` in your tool's folder (top level, or one level down):

```json
{ "label": "Fun Tools", "description": "Calculators for silly builds.", "entry": "index.html", "order": 10 }
```

On the next build the folder is copied to `public/embed/<folder>/`, a tab appears
in the nav and on the home page, and `/tools/<folder>` shows `entry` in a frame
that grows to fit it. Keep paths inside the folder relative.

## Run locally

```bash
cd web
npm install
cp .env.example .env.local   # then paste your Riot API key
npm run dev
```

Open http://localhost:3000.

## Riot API key

The key lives only in the `RIOT_API_KEY` environment variable and is read on
the server (`src/lib/riot.ts`). The browser calls this site's own API routes,
never Riot directly, so the key is never sent to visitors. Riot responses are
cached for a few minutes to save rate limit.

Example route: `/api/riot/account?gameName=Name&tagLine=NA1&region=americas`.

## Keeping the site up to date

`npm run build` (and `npm run dev`) first runs `scripts/sync-embeds.mjs`, which
copies the embedded folders in. With Vercel connected, every push to `main`
rebuilds the site, so merged work from other threads and the daily China data
commits show up on their own. Each pull request also gets a preview deployment
built from its own branch.

## Deploy on Vercel

1. Import the GitHub repo in Vercel and set **Root Directory** to `web`.
2. Add `RIOT_API_KEY` under Project Settings → Environment Variables.
3. Every push to `main` deploys.

A development key expires every 24 hours, so a site that stays up needs a
Personal or Production key from the Riot Developer Portal.
