# PBE data

Structured findings from PBE datamines, for the website's PBE section.

- `kiwi-s3.json`: ARAM: Mayhem "Season 3" (codename Kiwi, series `Kiwi_S3`), datamined 2026-10-15. Covers the Fame band track, augments added/removed/changed, and Mayhem champion overrides.

PBE content can change before release. `meta.notes` lists known gaps in each file.
`description: null` means the augment was found but its tooltip wasn't summarized.

The datamine tooling (string-table hash resolvers, tooltip resolver, bin diff scripts) isn't in this repo yet.
