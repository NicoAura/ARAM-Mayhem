The pool, the number of cards per offer and the starting reroll come from the game files via CommunityDragon. The files have no weights, so every augment in a tier is treated as equally likely, and a reroll is treated as a fresh offer of the same tier. Which tier each offer is isn't in the files either, so set how many offers of each tier you get. Augments you already took, champion or build filters the server may apply, and Transmute or Pandora's Box rolls are not counted.
