Where the speed comes from

Base speeds, item stats and augment values come from the game files via CommunityDragon, with Mayhem's item changes applied. Speed is (base + flat bonuses) × (1 + all % bonuses) × any multipliers, then League's soft caps: above 415 only 80% of the extra counts and above 490 only half. No other cap was found in the game data. Conditional effects (actives, decaying bursts, out of combat bonuses) count at their peak when switched on, even if they could never all line up at once. Champion abilities and passives, runes, slows, Draw Your Sword's extra bonus for long-range champions and Sonata's song (no number in the data) are left out. Use the "Other" inputs for anything missing. The lane length is a rough guess, so change it if you know better.
