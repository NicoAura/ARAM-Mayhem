Where the haste comes from

Cooldowns and haste values come from the game files via CommunityDragon, with Mayhem's item changes applied. Cooldown is base × 100 ÷ (100 + Ability Haste), so every point of haste is worth the same and there is no cap. Abilities with charges, recasts or a cooldown set by the passive show their listed cooldown, and cooldown refunds (Archmage, Mystic Punch, Skilled Sniper and so on) are not counted.
