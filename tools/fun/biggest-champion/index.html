Where the size comes from

Size values come from the game files via CommunityDragon, with Mayhem's item changes applied. A champion's base size is its selection radius, the circle the game uses for clicking on the model. It tracks the visible body better than the gameplay collision radius, which only comes in a few steps (55, 65 and 80). Baron Nashor's is 180. Size bonuses are added together, so Goliath and Mad Scientist give +90%, not ×2.1. Effects that only last a few seconds (Growth Spurt, Dimension Shift, Lifeline items, ultimates) are counted as if they all happen at once. The game files have no size value for Cho'Gath's Feast stacks, Volibear's R, Zac or Sion, so Cho'Gath gets an input for your own value and the others are left out.
